# 데이터 출처와 근거 확인

오름이 쓰는 데이터와 계산에 넣은 숫자의 출처(URL)·기준일·확인 상태를 정리한 폴더입니다. 같은 내용을 CSV와 Excel로 둡니다.

| 파일 | 내용 | 관리 방법 |
|---|---|---|
| [sources.csv](sources.csv) | 데이터·문서 22개: 구분, 제공기관, 문서번호, 발령일, 적용 기준일, URL | 직접 수정 (원본) |
| [value_checks.csv](value_checks.csv) | 계산에 쓰는 숫자 30개: 사용 값, 근거 자료, 원문 위치, 근거 수준, 팀 확인 칸 | 직접 수정 (원본) |
| [regions.csv](regions.csv) | 전국 시군구 230곳과 유형(자치구·시·군·특례시 등). `python data/build_regions.py`가 지역별 기준값을 rules.json에 만든다 | 직접 수정 (원본) |
| [services_collected.csv](services_collected.csv) | AI 규칙 변환에 쓴 복지서비스 원문 69건: 서비스 ID, 복지로 URL, 수집일 | 스크립트가 생성 |
| [오름_데이터_출처.xlsx](오름_데이터_출처.xlsx) | 위 세 표 + 분석 결과 2개를 시트별로 모은 Excel | 스크립트가 생성 |
| `../../analysis/output/*.xlsx` | 분석 결과 CSV의 Excel 판 | 스크립트가 생성 |

```bash
pip install -r requirements.txt
python analysis/cliff_analysis.py      # 분석 CSV를 먼저 최신으로
python data/sources/build_tables.py    # CSV·Excel 다시 만들기
```

## 기준일
- **적용 기준: 2026년.** 2026-01-01 시행 고시·조례의 값을 씁니다. 2027년 고시(기준 중위소득 제2026-157호, 주거급여 제2026-455호, 교육급여 제2026-21호)는 이미 발령됐지만 2027-01-01 시행이라 반영하지 않았습니다.
- **수집일:** 공공데이터포털 복지서비스 API 2026-11-14. 복지로 학습용 원문은 2026-11에 화면을 옮겨 적었습니다 (첫 커밋 2026-11-14).
- **URL·문서번호 확인일:** 2026-11-18. 국가법령정보센터·공공데이터포털에서 각 문서가 열리고 제목·번호·시행일이 맞는지 확인했습니다.
- **고시가 바뀐 경우:** 기초연금 고시는 2026-07-28 개정(제2026-156호)됐지만 2026년 선정기준액·기준연금액 조항은 같습니다. 경산시 출산장려 조례는 2026-07-08 개정됐지만 신청 기한만 바뀌었고 금액은 같습니다.

## 근거 수준
`value_checks.csv`의 **현재 근거 수준** 칸:

| 수준 | 뜻 | 개수 |
|---|---|---|
| 1차 원문 | 고시·조례·법령 원문이 근거 | 12 |
| 복지로·공식 안내 | 복지로 서비스 상세, 담당 기관 누리집, 지자체 사업계획 | 4 |
| 2차 자료 | 보도자료·다른 지자체 안내·언론 보도 등 → **1차 원문으로 다시 확인 필요** (V09·V16은 일부 추정 포함) | 11 |
| 추정 | 공식 숫자가 없어 통계·가정으로 계산 (V10 의료급여 가치, V29 진료비 감면 가치) | 2 |

## 직접 확인하는 방법
AI 도구로 정리한 값을 그대로 쓰지 않기 위해, 숫자마다 사람이 원문을 직접 열어 대조합니다.

1. `오름_데이터_출처.xlsx`의 **수치 확인표** 시트를 엽니다.
2. 행마다 **근거 자료** 번호(S01~S22)를 **데이터 출처** 시트에서 찾아 URL을 엽니다.
3. **원문 위치**(조항·쪽)에서 값을 찾아 노란 칸에 적습니다: 확인자, 확인일, 원문 값, 일치(O/X), 메모.
4. 다르면(X) `data/rules.json`의 값을 고치고 이슈로 남긴 뒤, `value_checks.csv`도 고쳐 커밋합니다.
5. 고시 표가 이미지인 항목(V01~V03, V15)은 화면을 보고 값을 읽어야 합니다.

**AI 사전 대조** 칸은 AI 도구가 2026-11-18에 원문 본문과 비교한 결과입니다. '원문 본문과 일치'인 항목(V11~V13, V26)도 팀이 한 번 더 직접 확인합니다.
