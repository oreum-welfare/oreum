# 오름 기획안

> **오름 — AI 기반 복지 절벽 탐지·자립경로 시뮬레이터**
> 2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회 출품작 · 작성일 2026-11-13 · 버전 0.2

---

## 1. 한 줄 소개
소득이 조금 늘 때 여러 복지 혜택이 한꺼번에 끊겨 **"일할수록 손해"가 되는 구간(복지 절벽)**을 AI로 찾아 보여 주고, 손해 없이 넘어가는 **자립 경로**를 함께 설계하도록 돕는 웹 서비스.

## 2. 배경과 문제

### 2.1 복지 절벽이란
저소득 가구의 소득이 기준선(기준중위소득의 일정 비율)을 넘는 순간, 그 기준에 묶인 여러 혜택이 동시에 사라져 **근로소득 + 혜택의 합계가 오히려 줄어드는 현상**.

### 2.2 왜 문제인가
- **탈수급 유인 저하:** 수급자가 취업·소득 증가를 망설이게 만든다.
- **정보 부족:** 복지 제도가 수백 개이고 기준이 제각각이라 개인이 미리 계산할 수 없다.
- **지역 차이:** 같은 소득이어도 사는 지역에 따라 혜택과 절벽 위치가 다르다.

### 2.3 기존 서비스의 한계
| 서비스 | 하는 일 | 한계 |
|---|---|---|
| 복지로 모의계산 | 서비스별 수급 가능성 계산 | 현재 소득 **한 시점**, 서비스를 **하나씩** 계산 |
| 보조금24 · 복지멤버십 | 지금 받을 수 있는 혜택 안내 | **"소득이 오르면 무엇을 잃나"**는 알려주지 않음 |
| 민간 계산기 | 중위소득 대비 비율 계산 | 여러 급여 합산, 절벽 탐지 없음 |

## 3. 해결 방안

```
[복지로 서비스 원문] → [AI가 선정기준을 판정 규칙으로 변환] → [판정 엔진]
      → [소득·지역별 시뮬레이션] → [절벽 탐지] → [자립 경로 안내]
```

- 사용자가 가구 정보와 소득을 넣으면, 소득을 0원부터 1만 원 단위로 올려 가며 받는 혜택을 모두 계산한다.
- 합계가 줄어드는 지점을 **절벽**으로 표시하고, 그때 **사라지는 혜택**과 **손해 금액**을 알려준다.
- 절벽을 넘는 방법(자산형성 지원, 근로소득공제, 자활사업 등)을 함께 안내한다.

## 4. 대상 사용자
| 사용자 | 사용 장면 | 얻는 것 |
|---|---|---|
| **자활센터·고용센터 사례관리자** (주 사용자) | 상담 중 "이 일자리로 옮기면 어떻게 되나" 확인 | 근거 있는 자립 계획 수립 |
| 수급자 본인 | 취업·이직 결정 전 확인 | 손해 구간을 미리 알고 대비 |
| 지자체·정책 연구자 | 제도 설계 검토 | 혜택이 겹쳐 끊기는 구간에 대한 근거 |

| (예정) 시군구별 수급자 통계 | 공공데이터포털, KOSIS | 절벽 구간 가구 수 추정 |

## 6. AI 활용
- **역할:** 사람이 읽는 선정기준 문장을 컴퓨터가 계산할 수 있는 규칙으로 변환
  - 예: "소득인정액이 기준중위소득 50% 이하" → `소득인정액 ≤ 중위소득 × 0.5`
- **필요성:** 시군구마다 형식이 다른 수백 건의 문장을 사람이 일일이 변환할 수 없음. 기준 변경에도 빠르게 대응 가능.
- **검증 결과:** 표본 13건(중앙 8, 지자체 5) 중 **11건(85%) 자동 판정 가능**.

## 7. 지금까지의 발견
1. **절벽 위치:** 중위소득 48~50% 구간에서 주거급여·교육급여·에너지바우처·통신비 감면이 **동시에** 끊긴다.
2. **자격 연쇄 변동:** 지자체 혜택은 소득 금액이 아니라 **수급 자격**에 연동된다.
   - 경산 생활안정자금: 수급자만 → 탈수급 시 사라짐
   - 대구 북구 건강보험료지원: 비수급자만 → 탈수급 시 새로 생김
3. **지역 차이:** 기초연금 재산 환산(대도시/중소도시), 주거급여 기준임대료(급지), 지자체 혜택이 대구와 경산에서 다르다.

## 9. 기대 효과와 사업화
- **사회적 효과:** 근로 의욕 유지, 자립 지원, 제도 개선 근거 제공
- **확산 단계**
  1. 경산시 자활센터·행정복지센터 상담 도구로 시범 운영
  2. 시군구 단위 확대 (AI 변환으로 지역 확장 비용 최소화)
  3. 사회보장정보시스템(행복이음) 연계로 실제 수급자 정보 기반 정밀 상담
- **근거:** 미국 CLIFF가 여러 주로 확산되어 효과가 검증된 모델
- **ESG:** 사회(S) — 근로·자립 지원 / 거버넌스(G) — 데이터 기반 제도 개선
