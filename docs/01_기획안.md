# 오름 기획안

> **오름: AI 기반 복지 절벽 탐지·자립경로 시뮬레이터**
> 2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회 출품작 · 팀 꼬마돌 · 작성일 2026-11-14 · 버전 0.3

---

## 1. 한 줄 소개
소득이 조금 늘 때 여러 복지 혜택이 한꺼번에 끊겨 **"일할수록 손해"가 되는 구간(복지 절벽)**을 찾아 보여 주고, 손해 없이 넘어가는 **자립 경로**를 함께 설계하도록 돕는 웹 서비스.

## 2. 배경과 문제

### 2.1 복지 절벽이란
저소득 가구의 소득이 기준선(기준중위소득의 일정 비율)을 넘는 순간, 그 기준에 묶인 여러 혜택이 동시에 사라져 **근로소득 + 혜택 합계가 오히려 줄어드는 현상**.

### 2.2 왜 문제인가
- **탈수급 유인 저하:** 수급자가 취업·소득 증가를 망설이게 만든다.
- **정보 부족:** 제도가 수백 개이고 기준이 제각각이라 개인이 미리 계산할 수 없다.
- **지역 차이:** 같은 소득이어도 사는 지역에 따라 혜택과 절벽 위치가 다르다.

### 2.3 기존 서비스의 한계
| 서비스 | 하는 일 | 한계 |
|---|---|---|
| 복지로 모의계산 | 서비스별 수급 가능성 계산 | 현재 소득 **한 시점**, 서비스를 **하나씩** 계산 |
| 보조금24 · 복지멤버십 | 지금 받을 수 있는 혜택 안내 | **"소득이 오르면 무엇을 잃나"**는 알려 주지 않음 |
| 미국 CLIFF (애틀랜타 연준) | 소득 구간별 여러 제도 합산 | 미국 제도, 규칙을 사람이 입력 |

## 3. 해결 방안

```
[복지로 원문 · 공공데이터포털 API] → [AI가 판정 규칙으로 변환] → [사람 검수] → [rules.json]
                                     [고시·사업안내·조례] ─────────────────────┘
[rules.json] → [판정 엔진] → [소득 0원~중위 100% 시뮬레이션] → [절벽 탐지] → [자립 경로 안내]
```

- 가구 정보와 소득을 넣으면, 소득을 1만 원 단위로 올려 가며 받는 혜택을 모두 계산한다.
- 합계가 1,000원 이상 줄어드는 지점을 **절벽**으로 표시하고, **끊기는 혜택**과 **손해 금액**을 알려 준다.
- 절벽을 넘는 방법(자산형성 지원, 근로소득공제, 자활사업 등)을 함께 안내한다.

## 4. 대상 사용자
| 사용자 | 사용 장면 | 얻는 것 |
|---|---|---|
| **자활센터·고용센터·행정복지센터 사례관리자** (주 사용자) | 상담 중 "이 일자리로 옮기면 어떻게 되나" 확인 | 근거 있는 자립 계획 |
| 수급자·차상위 가구 | 취업·이직 결정 전 확인 | 손해 구간을 미리 알고 대비 |
| 지자체·정책 담당자 | 제도 설계 검토 | 혜택이 겹쳐 끊기는 구간에 대한 근거 |

## 5. 활용 데이터
| 데이터 | 출처 | 활용 |
|---|---|---|
| 중앙부처·지자체 복지서비스 정보 | 한국사회보장정보원 (복지로, 공공데이터포털 API) | AI 판정 규칙의 원천. 원문 43건 수집 (경산·대구 북구·영천), 지자체 API 연동 완료 (경산 18건, 복지로 화면 원문과 14건 중 13건 일치) |
| 2026 기준중위소득, 급여별 선정기준 | 보건복지부·국토교통부 고시 | 기준선 |
| 급여별 지원 금액 | 고시·사업안내·복지로 | 절벽 깊이 |
| 지자체 조례·사업계획 | 대구 북구, 경산시 | 시군구 자체 혜택 |

반영 제도 **17개** (중앙 12, 지자체 5). 항목마다 근거와 확인 상태를 `rules.json`의 `verification`에 기록. 추정값 3개(의료급여 가치, 경산 진료비 감면, 장애인연금 일부)는 추정이라고 표시.

## 6. AI 활용
- **역할:** 사람이 읽는 선정기준 문장을 계산 가능한 판정 규칙(JSON)으로 변환하고, 조건마다 원문 근거를 인용
  - 예: "소득인정액이 기준중위소득 50% 이하" → `income_recognized_pct_median <= 50`
- **필요성:** 시군구마다 형식이 다른 수백 건의 문장을 사람이 일일이 옮길 수 없음. 기준 변경에도 빠르게 대응
- **검증:** 팀이 만든 정답과 비교해 채점. 학습용 13건 85%, 처음 보는 경산 14건 36% → 원인(판정 불가 서비스 구분) 분석 후 3차 프롬프트를 처음 보는 대구 북구·영천 16건으로 시험해 **81%** (학습용은 62%로 하락, 균형 조정 필요). 지어낸 조건 0건
- **사람 검수:** AI 결과는 검수 화면에서 승인된 것만 반영 (AI가 판정 불가 서비스를 자주 놓치기 때문)

## 7. 지금까지의 발견
1. **가장 큰 절벽:** 한부모 + 자녀 2명 가구, 월소득 498만 원에서 아동양육비가 끊겨 월 450,204원 손해.
2. **절벽이 몰리는 구간:** 혜택 종료 96건 중 28건이 기준중위소득 70~75%. 중위 50% 기준 혜택들이 근로소득공제 30% 때문에 실제 소득 약 71%에서 동시에 끊긴다.
3. **자격 연쇄 변동:** 지자체 혜택은 소득 금액이 아니라 **수급 자격**에 연동된다.
   - 경산 생활안정자금: 수급자만 → 탈수급 시 사라짐
   - 대구 북구 건강보험료지원: 비수급자만 → 탈수급 시 새로 생김
4. **제도 개선 효과 (가상 시나리오):** 혜택을 기준선 위 중위 10%p 구간에서 서서히 줄이면 절벽 41개 → 16개, 가장 큰 손해 450,204원 → 7,277원.
5. **지역 차이:** 주거급여 급지(대구 북구 3급지, 경산 4급지)와 지자체 혜택 때문에 같은 가구도 손해 금액이 다르다 (예: 1인 노인 최대 손해 북구 141,626원 / 경산 106,626원).

## 9. 기대 효과와 사업화
- **사회적 효과:** 근로 의욕 유지, 자립 지원, 제도 개선 근거
- **확산 단계**
  1. 경산시 자활센터·행정복지센터 상담 도구로 시범 운영
  2. API + AI 변환 + 사람 검수로 시군구 확대
  3. 사회보장정보시스템(행복이음) 연계로 실제 수급 정보 기반 정밀 상담
- **ESG:** 사회(S): 근로·자립 지원 / 거버넌스(G): 데이터 기반 제도 개선, 책임 있는 AI 활용
