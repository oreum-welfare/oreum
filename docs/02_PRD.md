# 오름 PRD (제품 요구사항 문서)

> 작성일 2026-11-13 · 버전 0.2 · 상태: 프로토타입 개발 중

---

## 1. 제품 개요
| 항목 | 내용 |
|---|---|
| 제품명 | 오름 |
| 형태 | 웹 서비스 (브라우저에서 사용, 설치 불필요, 모바일 대응) |
| 배포 | Vercel (정적 웹, 서버 없음) |
| 한 줄 정의 | 소득이 바뀔 때 받는 복지 혜택의 변화를 계산해 복지 절벽을 찾아 주는 시뮬레이터 |

## 2. 목표

### 2.1 제품 목표
1. 사용자가 **1분 안에** 자기 가구의 복지 절벽 위치와 손해 금액을 확인할 수 있다.
2. 절벽마다 **사라지는 혜택**과 **근거(선정기준)**를 함께 보여 준다.
3. 같은 가구를 **지역별로 비교**할 수 있다.

### 2.2 프로젝트 목표 (마일스톤)
| 시점 | 목표 |
|---|---|
| 11/16 | 배포 URL 확보, 공모전 제출 |
| 11/17 | 중간 발표 시연 (예시 가구 → 슬라이더 → 절벽 → 지역 비교) |
| 11/24 | 데이터 분석 결과 반영, 시연 영상 |
| 12/3 | AI 자동 변환 결과 시연 (본선 진출 시) |

### 2.3 성공 지표
| 지표 | 목표값 | 현재 |
|---|---|---|
| 자동 판정 가능 비율 (표본) | 70% 이상 | **85% (11/13건)** |
| 웹·분석 엔진 계산 일치 | 100% | **100% (테스트 가구 8개)** |
| 반영 급여 수 | 10개 이상 | 14개 (중앙 9, 지자체 5) |
| 임시 금액 비율 | 0% (11/15까지) | 진행 중 |
| AI 자동 변환 정확도 | 측정 후 공개 | 미구현 |
| 시연 소요 시간 | 1분 30초 이내 | 리허설 예정 |

## 3. 범위

### 3.1 포함 (v0.x)
- 지역 2곳: 대구광역시 북구, 경상북도 경산시
- 중앙부처 급여 9종: 생계·의료·주거·교육급여, 기초연금, 에너지바우처, 근로장려금, 자녀장려금, 이동통신요금 감면
- 지자체 혜택 5종: 경산 진료비 감면·출산장려금·생활안정자금·다자녀가정 지원, 대구 북구 건강보험료지원
- 입력: 나이, 배우자, 자녀(학교급별), 신생아, 장애인, 한부모, 거주 기간, 월 근로소득

### 3.2 제외 (향후 확장)
- 재산 입력, 부양의무자 기준
- 근로소득 외 소득 (사업·연금·재산 소득)
- 전국 시군구 확대
- 회원가입, 상담 기록 저장
- 행복이음 등 실제 수급자 정보 연계

## 4. 사용자 시나리오

### 시나리오 A. 사례관리자 상담 (핵심)
> 경산시 자활센터 상담사가 한부모 어머니(초·중학생 자녀 2명, 월 300만 원)와 상담한다.
1. '한부모 + 자녀 2명' 예시를 고르고 소득을 300만 원으로 맞춘다.
2. 다음 절벽 알림: "월 307만 원이 되면 의료급여가 끊겨 손해".
3. 슬라이더를 383만 원까지 올리자 교육급여·에너지바우처·통신비가 동시에 사라지는 것이 보인다.
4. 자립 경로 탭에서 자산형성 지원 제도를 함께 안내한다.

### 시나리오 B. 수급자 본인 확인
> 1인 청년이 일자리 제안을 받고 실제로 이득인지 확인한다.

### 시나리오 C. 정책 담당자 검토
> 지자체 담당자가 여러 가구 유형을 넣어 보며 절벽이 집중되는 구간을 확인한다.

## 6. 비기능 요구사항
| ID | 요구사항 |
|---|---|
| NFR-01 | **정확성:** 웹(JS)과 분석(파이썬) 엔진의 계산 결과가 일치해야 한다 (오차 0.01원 미만). |
| NFR-02 | **단일 데이터 원천:** 규칙과 금액은 `rules.json` 한 파일에서만 관리한다. |
| NFR-03 | **성능:** 슬라이더 조작 시 화면이 즉시(체감 지연 없이) 갱신된다. |
| NFR-04 | **반응형:** 375px 휴대폰 화면에서 가로 스크롤 없이 사용 가능하다. |
| NFR-05 | **가용성:** 서버 없이 정적 배포하여 발표 중 앱이 잠드는 문제가 없다. |
| NFR-06 | **개인정보:** 입력값을 서버로 전송하거나 저장하지 않는다 (브라우저 안에서만 계산). |
| NFR-07 | **투명성:** 모든 혜택에 근거를 표시하고, 임시 금액은 '임시'로 명시한다. |

## 7. 가정과 제약
- 재산 0원, 부양의무자 기준 미적용
- 소득인정액 = 근로소득 × (1 − 근로소득공제율) + 기초연금
- 주거급여는 임차가구, 실제 임차료 ≥ 기준임대료 가정
- 차상위 = 비수급 + 소득인정액 ≤ 중위 50%로 근사
- 근로·자녀장려금은 전년도 소득 기준 지급이지만 같은 해 월 환산으로 표시
- **참고용이며 실제 수급 판정이 아님**
