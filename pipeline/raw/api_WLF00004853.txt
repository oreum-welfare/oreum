# 서비스명: 경산시 다자녀가정 지원사업
# 제공주체: 경상북도 경산시
# 출처: 공공데이터포털 복지서비스 API (servId=WLF00004853)

[서비스 요약]
다자녀가정의 경제적 부담을 경감하고 출산양육에 유리한 환경 조성하여 출생률 제고 및 인구증가에 기여
[지원대상]
사업연도 기준 7세~18세까지의 셋째 이상 자녀
[선정기준]
신청일 현재 보호자와 지원대상 자녀가 시에 3년 이상 계속하여 주민등록이 되어 있는 경우에 지급 (다만, 재혼 가정인 경우에는 주민등록이 같이 되어 실제 함께 생활하는 자녀의 수만 인정)
[서비스 내용]
다자녀가정 지원금 지급
[신청방법]
방문 신청(주소지 읍면동 행정복지센터 방문 신청)
